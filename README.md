# tg-chat-bot

Telegram-бот для нашей беседы: анкеты, браки, таджикистан, таджик дня, казино на таджикоинах, статистика и сглыпа.

> Telegram показывает в меню только латинские команды. Кириллические варианты (`/таджик`, `/ник`, `/кто`…) тоже работают.

## Команды

### Развлечения
| Команда | Что делает |
|---|---|
| `/tajik` (`/таджик`) | 🇹🇯 Таджик дня — раз в сутки с драматичным поиском. Таджик дня получает +2 к `/d20` |
| `/tajiktop` | Зал славы таджиков дня |
| `/tadjikistan` | Случайный таджикистан-ивент (кулдаун 5 минут на беседу) |
| `/d20 [порог]` | Бросок d20 с бонусами от участников беседы |
| `/dnd` (`/днд`) | 🐉 Случайный ивент из D&D |
| `/who вопрос` (`/кто`) | 🔮 Бот выбирает, кто из беседы |
| `/orgy` (`/оргия`) | Оргия-опрос |

### Казино «Золотой казан» (валюта — Таджикоин 🪙, на старте у всех 1 000)
| Команда | Что делает |
|---|---|
| `/casino` | Все игры и правила |
| `/roulette 100 красное` | 🎡 Рулетка: цвет, чёт/нечет, 1-18/19-36 — ×2; число или зеро — ×36 |
| `/slots 100` | 🎰 Однорукий бандит (анимация Telegram): 777 — ×20, три одинаковых — ×7, две семёрки — ×2 |
| `/coin 100 орёл` | 🪙 Монетка, ×2 (без ставки — просто подбросить) |
| `/rr` | 🔫 Русская рулетка: барабан общий на беседу, с каждым выстрелом страшнее |
| `/duel 100` (ответом) | ⚔️ Дуэль на кубиках на таджикоины |
| `/balance`, `/bonus`, `/forbes`, `/give 100` (ответом) | Кошелёк, ежедневный бонус, самые богатые, перевод |

Ставка `все` — ва-банк.

### Кулдауны и спам-день
- У `/d20`, `/who`, `/dnd` и игр казино кулдаун **20 минут** на человека.
- Примерно раз в две недели (в случайный день) в 10:00 бот объявляет **спам-день**: до 23:59 все кулдауны — 5 секунд.

### Беседа
| Команда | Что делает |
|---|---|
| `/stats` | 📈 Статистика беседы: болтуны, слова, номинации (сапожник, хохотун, таджиковед…) |
| `/stats я` / `/stats @username` / ответом | 📊 Досье: место, слова, фирменные словечки, мат, режим сна, браки, титулы |
| `/info`, `/anketa`, `/rules`, `/nick` | Анкеты, правила, ник |
| `/brak`, `/razvod`, `/families` | Браки |

### Сглыпа
Раз в 150–200 сообщений бот отвечает случайной фразой, склеенной из сообщений самой беседы (иногда — стикером или опросом). Если ответить на его фразу или упомянуть бота — ответит ещё.

## База данных и бэкапы

- База лежит в `/app/data/bot.db` — на bothost эта папка **не стирается** при обновлении из гита (пока тариф оплачен).
- Бот сам бэкапит базу **в личку хозяину**: после изменений раз в час, через ~5 минут после важных событий (браки, анкеты, ники, таджик дня) и перед выключением. Последний бэкап закреплён.
- Если диск почистили (например, тариф не продлился), бот при запуске сам скачает закреплённый бэкап.
- В личке с ботом: `/backup` — бэкап прямо сейчас, `/restore` ответом на файл бэкапа — откатить базу к нему.

⚠️ Чтобы бэкапы работали, хозяин должен один раз написать боту `/start` в личку.

### Переезд со старой версии
Старая версия держала базу в корне проекта. Один последний раз: останови бота, положи `bot.db`, `bot.db-wal`, `bot.db-shm` рядом с `bot.py`, запусти — бот сам перенесёт базу в `/app/data` и дальше будет её бэкапить.

### Импорт истории
Экспорт беседы из Telegram Desktop (JSON, без медиа) можно положить рядом с ботом как `result.json` — бот при запуске доберёт из него фразы для сглыпы (и статистику, если чат ещё не импортировался). Повторный импорт ничего не задваивает.

## Скрытое для хозяина
Только для `OWNER_ID` (по умолчанию @SkullOfGods), остальные этих команд не видят:
- `/debug` — панель: состояние базы и бэкапов, спам-день вкл/выкл, сброс кулдаунов, «сглыпа, скажи», перевыбор таджика дня, последние ошибки.
- `/say текст` — написать в беседу от имени бота.

## Настройка

Переменные окружения — в [.env.example](.env.example). Обязателен только `BOT_TOKEN`.

В @BotFather: `/setprivacy` → `Disable` (чтобы бот видел все сообщения). В беседе бот должен быть **администратором** — тогда он узнаёт, кто пришёл и ушёл, и не выбирает ушедших в ивентах.

Локальный запуск:
```bash
pip install -r requirements.txt
python bot.py
```

## Структура

```
bot.py            — точка входа: запуск, меню команд, фоновые задачи
config.py         — настройки из переменных окружения
loader.py         — общие объекты: бот, диспетчер, база
db.py             — SQLite: схема, миграции, запросы
backup.py         — бэкапы базы в Telegram и восстановление
members.py        — участники беседы: имена, упоминания, случайный участник
limits.py         — кулдауны и спам-день
scheduler.py      — объявления в беседы, проверка спам-дня
sglypa.py         — генератор фраз (цепи Маркова)
textstats.py      — разбор слов: стоп-слова, мат, смех, фирменные словечки
texts.py          — все тексты бота
import_history.py — импорт экспорта истории из Telegram
handlers/         — обработчики команд по темам
```
